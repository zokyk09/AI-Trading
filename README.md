# AI Diana Trading System

AI Diana adalah sistem trading berbasis Machine Learning
yang terhubung dengan MetaTrader 5.

## Features

- XAUUSD trading
- EURUSD trading
- AI signal BUY / SELL
- Confidence prediction
- RSI indicator
- EMA20 indicator
- EMA50 indicator
- Manual trading
- Auto trading
- Stop Loss
- Take Profit
- Account monitoring
- Position monitoring
- Trading history
- React dashboard
- FastAPI backend
- MetaTrader 5 integration

## Technology

- Python
- FastAPI
- MetaTrader 5
- Machine Learning
- React
- TypeScript
- Vite

## Project Structure

backend/
frontend/
models/

## Installation

Install Python dependencies:

pip install -r requirements.txt

Install frontend:

cd frontend
npm install

## Run Backend

python -m uvicorn backend.server:app --reload

## Run Frontend

cd frontend
npm run dev
